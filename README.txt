ComfyUI-ImageGallery

Custom node: Load Image Gallery

UI order:
  [ Preview folder ]
  image dropdown
  native upload image button

Gallery:
- responsive thumbnail grid
- folder selector fixed at bottom
- search by filename
- refresh button
- single click selects image and keeps gallery open
- double click selects and closes
- remembers current/last folder for the node while the page is open
- recursively supports ComfyUI/input subfolders

Install the folder as:
C:\Users\ATOM\Documents\ComfyUI\custom_nodes\ComfyUI-ImageGallery
Then restart ComfyUI and hard refresh browser (Ctrl+F5).
